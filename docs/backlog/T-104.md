## Goal
Recipe import (matprat.no, photo) creates own ingredients with protein class Unknown, so the imported recipes end up with food type Unknown until someone classifies each ingredient by hand. On 2026-11-01 all 26 local own ingredients from earlier imports were Unknown and had to be set (Grillet kylling = Chicken, Kjøttpølse/Karbonadedeig/Pepperoni = Meat, Torskefilet = Fish, cream and grated cheese = AnimalProduct, the rest None). The importer should suggest a class for each new own ingredient (best effort: match against the global catalog's classes and simple Norwegian keywords such as kylling, laks, torsk, reker, svin, bacon, storfe, lam, deig, pølse, ost, fløte, egg), shown on the import review screen so the user can change it before saving.

## Acceptance criteria
- [x] Pure Domain suggester with unit tests (the 26 names above give the classes above)
- [x] Import review shows the suggested class per new ingredient; the user can change it
- [x] Saving an import with suggestions gives the expected food type; `./scripts/verify.sh` green
