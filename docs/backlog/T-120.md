## Goal
An Owner can add the household's own Anthropic API key (from the Claude Console). AI features then use that key instead of the shared app key, without the shared daily limit. The key is checked once when added, stored encrypted (T-099), never shown again, never logged, and can be removed; deleting the household deletes it. If the own key fails (revoked, out of credit), the household is told and can fall back to the shared limit.

## Acceptance criteria
- [ ] Spec agreed; key stored per T-099 (encrypted, keys outside the database), tenant entity in the isolation suite
- [ ] Owner-only add/remove; never returned by the API or logged (tests)
- [ ] AI calls use the household key when present, the shared key with its limits otherwise; usage still recorded
- [ ] UI to add, test and remove the key (nb + en); `./scripts/verify.sh` green
