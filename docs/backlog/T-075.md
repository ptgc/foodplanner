## Goal
A recipe remembers where it came from so the user can go back to the original if an import looks wrong (Q-018). Recipe gets an optional SourceUrl and SourceName; saving an import fills them; the recipe page shows "Original recipe: <site> ↗"; the user can edit or clear them. Existing recipes saved from imports are backfilled from RecipeImports.SourceUrl / SavedRecipeId.

## Context
Read CLAUDE.md, docs/domain.md (Recipes, Recipe import, Q-017: SourceUrl is kept after save), docs/questions/Q-017.md and Q-018.md.

## Out of scope
Downloading or showing the source's images; scraping more metadata.

## Acceptance criteria
- [ ] Recipe has optional SourceUrl (http/https only, validated, max length) and SourceName (derived from the host if not given); returned in recipe detail; editable in the recipe form
- [ ] Saving an import sets them; the migration backfills existing recipes from their saved imports
- [ ] Recipe detail shows a translated "Original recipe" link (opens in a new tab with rel="noopener noreferrer"), only when set
- [ ] Tests: API (save from import, edit, validation, backfill), Vitest (link shown/hidden), Playwright (imported recipe shows the link)
