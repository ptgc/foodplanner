## Goal
Import a recipe from a URL (schema.org Recipe JSON-LD) or pasted text into structured ingredients, storing the original text only as an import artifact.

## Context
Read CLAUDE.md, docs/domain.md and relevant ADRs in docs/adr/. Parser strategy (rule-based or LLM-assisted) is a product and cost decision: raise a question first.

## Out of scope
Import review UI (T-043), scraping sites that disallow it.

## Acceptance criteria
- [ ] Ingredients parsed to quantity, unit and ingredient id; unmatched ones are flagged for manual mapping
- [ ] Original text kept only in the import artifact (CLAUDE.md rule 5)
- [ ] URL fetching is SSRF-safe: private and link-local ranges blocked, size and time limits enforced
- [ ] Tenant isolation test coverage added for the new entities

## Verification
`./scripts/verify.sh` green, plus the checks above evidenced in tests or PR notes.
