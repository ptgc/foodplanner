## Goal
The app admin (T-096) gets emails with metrics they choose, daily or weekly. First metric: Claude usage on the shared app key (calls, input/output tokens, estimated cost, per household and in total, photo imports vs line help). The metric set is extensible (for example new households, recipes added, Oda fills). Households' own keys are counted as calls only (their cost is theirs).

## Acceptance criteria
- [ ] Spec agreed: metric list, how often, recipients, how cost is estimated (price table in config)
- [ ] Metrics computed by a scheduled job from recorded usage; no personal data beyond household ids in the email
- [ ] Admin chooses metrics and frequency; email via the T-017 provider; tests
- [ ] `./scripts/verify.sh` green
