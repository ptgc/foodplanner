## Goal
Architect request 2026-11-24: the app works and is a good starting point, but it should be easier to use and feel modern and fresh. The design update has two parts, done in this order:
1. **This task: function and flow.** Rearrange screens and controls, and make the main user flows shorter and clearer.
2. **T-136: the look.** Colours, type, images, cards and spacing. It starts after the flow changes from this task have landed.

## Context
- The main flows to walk through, at 390px on the local stack:
  - Sign in, then first start and an empty household. This links to T-131, Kom i gang.
  - Add a recipe, three ways: by hand, from a link or import, and from a photo.
  - Plan the week, as an adult and in kid mode.
  - Shopping list, then the Oda cart and Oda choices. Sync with Oda (T-130) is part of this flow.
  - Cooking from a recipe.
  - Household and members, and account.
- How the review works:
  1. Claude walks each flow in the browser and takes screenshots.
  2. For each flow, Claude notes the number of taps, dead ends, unclear labels, controls in odd places, missing feedback, and what is repeated across screens.
  3. Claude proposes changes, each with a before and after sketch, and ranks them by value against effort.
  4. The architect picks which ones to do.
- Only the chosen changes are built. Each becomes its own small frontend task, or a backend one where needed.
- Rules that stay: mobile-first at 390px, touch targets of at least 44px, translated text in en and nb, and the web bundle budget.
- Order against T-131 (Kom i gang and Help): agree the first-start flow here before T-131 is built, or fold it into T-131.
