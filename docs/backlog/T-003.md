## Goal
Local only (iteration L1). Multi-stage API Dockerfile (non-root; a chiseled base if it works, otherwise note why), nginx web Dockerfile (placeholder SPA until T-018, proxies /api to api, non-root), docker-compose.yml with SQL Server, a one-shot sql-init service that creates the `foodplanner` database (no app-startup migrations, CLAUDE.md), api and web. No password or connection string with a password is ever written to a tracked file, and no `.env` file holds one. Compose requires `MSSQL_SA_PASSWORD` from the environment (`${MSSQL_SA_PASSWORD:?run scripts/local-up}`) and builds the container API's `ConnectionStrings__Default` from it; `scripts/local-up` (T-018) reads the value from .NET user secrets and passes it to compose in-process. Azurite is added later by T-022. Nothing Azure-related.

## Context
