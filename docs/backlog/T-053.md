## Goal
Implement an Oda IShoppingListExporter that, on an Adult's tap, signs in to the household's shared Oda account for that one action, adds the list's items to the Oda cart and closes the connection, per the T-001 findings and the session-only decision (Q-024, Q-025). Nothing from Oda is stored. See the spec.

## Context
Read CLAUDE.md, docs/domain.md and relevant ADRs in docs/adr/. Depends on the ADR 0008 verdict; raise a question about ToS if T-001 flagged one.

## Acceptance criteria
- [ ] Session-only: no Oda access or refresh token, code or PKCE verifier is persisted (database, cache, cookie, file) or logged; the token lives only in memory for one action and is revoked at `/o/revoke_token/` when done, on error and on cancel (revoke and the disappearing connection in Oda's Privacy & security are checked in implementation, see the spec)
- [ ] Only Adults (Owner, Adult) can send; the user confirms before anything is added. A Child member and kid mode can never send to Oda, start an order or change the Oda cart (`403`; architect, 2026-11-03)
- [ ] Nothing is ordered or paid automatically
- [ ] Failures degrade to the share/copy export from T-050
