## Goal
Two non-blocking reviewer notes from T-053 (architect asked for them 2026-11-21):
1. The Oda return address (`Oda:WebOrigin` + `/oda/callback`) must use https everywhere except a local development host (exactly `localhost`, `127.0.0.1` or `[::1]`). With a plain-http non-local origin the Oda flow is treated as not configured (start returns the same ProblemDetails as a missing client id), and startup logs one warning without any secret.
2. If the request is cancelled (client disconnects) after the authorization code has been exchanged for a token, the token is still revoked: the revoke call must not use the request's cancellation token (use a short own timeout instead).
