## Goal
T-091 shows the normal adult shopping list in kid mode (reached by the cart icon). The T-026 spec's UI sketch asks for a kid view: product pictures where the catalog has them, a big tap target to check an item off, no adult controls (generate, weekly groceries, pantry, export, manual add) and as little text as possible. Found in the T-091 review (2026-11-02).

## Open point (ask the architect before building)
What should a kid be able to do on the list: only check off, or also add an item (e.g. by picture)? Recommendation: check off only.

## Acceptance criteria
- [ ] Kid list: big item tiles with picture (or a section icon when there is none), check off with one tap, no adult controls
- [ ] Same live updates and offline cache as the adult list
- [ ] Vitest and Playwright (mobile-390); `./scripts/verify.sh` green
