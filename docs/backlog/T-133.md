## Goal
Locally the compose api container never receives the Claude key or the photo-import switch, so photo import (T-118/T-119) and line help (T-077) are always off at http://localhost:3000. Pass them from .NET user secrets the same way other local secrets reach the container (scripts/_local-env.sh/.ps1 + docker-compose.yml): `AiImport__ApiKey` from `AiImport:ApiKey` (never printed), and the on/off switches `AiImport__Enabled` / `AiPhotoImport__Enabled` from user secrets or an env var, default off, with `scripts/local-secrets.*` able to set them on for local use. Document in README (local section): how to store the key and switch photo import on. Nothing secret in the repo; empty defaults keep everything off.

## Acceptance criteria
- [ ] With the key and switches set in user secrets, `scripts/local-up` gives a stack where photo-usage returns enabled; without them everything stays off
