## Goal
Store ASP.NET Data Protection keys (cookie and antiforgery encryption) in Blob Storage, protected by a Key Vault key, using managed identity. Without this every restart or extra replica logs users out and breaks antiforgery tokens.

## Context
Read CLAUDE.md, docs/domain.md and relevant ADRs in docs/adr/.

## Out of scope
Anything for test and prod environments (T-046).

## Acceptance criteria
- [ ] Keys survive a container restart and are shared by two replicas of the api
- [ ] Key protection uses Key Vault and managed identity; no secrets in the repo (CLAUDE.md rule 7)
- [ ] Local development uses Azurite and a local key, with no Azure dependency
- [ ] Bicep grants only the needed roles to the api identity

## Verification
`./scripts/verify.sh` green, plus the checks above evidenced in tests or PR notes.
