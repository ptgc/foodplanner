# Q-003: Rate limiting on auth endpoints: T-009 or T-047
Raised by: spec-writer / task T-009 (also affects T-010, T-011)
Status: answered

## Context
The T-009 spec turns on ASP.NET Core Identity lockout. Lockout is part of Identity configuration and limits password guessing per account. Lockout does not stop one client from spraying many accounts, flooding `register`, or guessing invite tokens. T-047 (M3, production hardening) lists "rate limiting on auth and import endpoints", so the backlog currently leaves auth endpoints without rate limits from M0 until M3. Behind nginx and Container Apps ingress, per-client limits also need forwarded-header handling to see the real client IP.

## Options
1. **App-level limits in T-009.** Use the ASP.NET Core rate limiter on `login`, `register` and (in T-011) invite accept. Partition by client IP, plus by normalised email for login. Over-limit requests get 429 ProblemDetails with `Retry-After`. Limits come from configuration. Forwarded headers are trusted only from the configured proxy. T-047 then adds edge or infra limits and tuning. Trade-off: slightly more T-009 scope and forwarded-header setup now.
2. **Keep the plan.** T-009 ships lockout only, and all rate limiting stays in T-047. Trade-off: no extra scope now, but dev and test are exposed to spraying until M3. The dev environment is public once T-007 deploys it.
3. **Edge-only limits in T-047.** Never add app-level limits; rely on the ingress or a WAF. Trade-off: no app code, but Container Apps ingress has limited per-path rate limiting and tests cannot prove the behaviour.

## Recommendation
Option 1. It is cheap with the built-in middleware, an integration test with a low configured limit can prove it, and it closes the gap before the dev environment is public. T-047 keeps the infra side and tuning.

## Answer (architect)
Decided 2026-10-22: option 1. T-009 adds app-level rate limiting on login, register and confirm-email, and registers the named limiter policies that T-010 (external sign-in) and T-011 (invite accept) attach to. Limits are configurable. T-047 keeps edge limits and tuning.
