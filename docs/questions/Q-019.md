# Q-019: Shopping list order follows the store layout
Raised by: architect (2026-10-28) / affects T-031, T-085, T-086, T-087
Status: answered

## Context
The shopping list sorts items alphabetically by name. In a store you walk the sections in a fairly fixed order, so an alphabetical list makes you go back and forth.

## Options
1. Keep alphabetical.
2. Fixed store-section order: every ingredient has a store section; the list is grouped and sorted by section, then name.
3. Option 2, later learning each household's own store order from the order items are checked off.

## Recommendation
Option 2 now, option 3 as a stretch task.

## Answer (architect)
Decided by the architect on 2026-10-28: option 2 now (T-085), option 3 as a stretch backlog task (T-086, not scheduled). Order given by the architect: fruit and vegetables first; then the chilled counter with fish, meat, cheese etc.; then the freezers with frozen food; then the chilled dairy shelf with milk, juice, sour cream, yoghurt etc.; and lastly dry goods. Details the orchestrator filled in (the architect can change them): eggs go with dairy, bread and baking with dry goods, and anything without a known section (manual items, own ingredients not yet assigned) goes last under "Other".

Addendum (architect, 2026-10-28): the household can register the stores it shops at and pick the store when shopping, so different stores are learned separately; and the section order per store can also be set manually. Added as T-087 (stores + manual order, after T-085); T-086 (learning) now works per store and depends on T-087.
