# Q-021: Recipe food type and weekly meal mix rules
Raised by: architect (2026-10-28) / affects T-089, T-090, T-026
Status: answered

## Context
The architect wants an adult to set weekly rules ("at least one fish and one vegetarian dinner a week"); as dinners are picked, recipes that no longer fit the required mix are filtered out. This needs every recipe classified by food type (fish, chicken, beef, vegetarian, vegan, ...). Tags Vegetar/Fisk/Kylling/Kjøtt already exist (T-023) but are optional and free to combine.

## Decision points
1. One type or several per recipe?
   a. Exactly one main type (the main protein) — simple rules and counting. **Recommended.**
   b. Several (e.g. Chicken + Pork) — a recipe counts toward each.
2. How is the type set?
   a. Derived from the ingredients (catalog ingredients get a protein class; Main, non-optional lines decide; meat beats fish beats vegetarian; no animal products = vegan) with a manual override in the editor. **Recommended** — imported recipes get a type for free.
   b. Set by hand on every recipe.
3. Relation to the existing tags Vegetar/Fisk/Kylling/Kjøtt.
   a. The food type replaces them (migrate tagged recipes, remove those tags). **Recommended** — one source of truth.
   b. Keep both, kept in sync automatically.
   c. Keep both, independent.
4. Rules: what can be set?
   a. Minimum per type per week (≥ 1 fish, ≥ 1 vegetarian), dinners only. **Recommended** to start.
   b. Minimum and maximum (e.g. ≤ 2 red meat).
5. Filtered out or just warned?
   a. Kids: recipes that would break the rules are hidden; adults: shown greyed out with the reason and can override. **Recommended.**
   b. Hidden for everyone, no override.
   c. Only a warning, nothing hidden.
6. How kids take part in planning (links to Q-020 point 7). The architect said "as the kids pick dinners", while the T-026 spec so far has kids only "liking" dishes.
   a. Kids like dishes (T-026) and can also pick a dinner for an open day of the week; the rules filter what they can pick. **Recommended** — matches the request.
   b. Kids only like; adults pick days and the rules filter the adults' choice.

## Recommendation
1a, 2a, 3a, 4a, 5a, 6a.

## Answer (architect)
Point 6, decided by the architect on 2026-10-28: "for the kids they should be able to make a week plan but then within the rules an adult has set for the household". So kids pick dinners for the days of the week (they make the week plan), and the household rules (T-090) decide which recipes they can pick for each remaining day. Points 1-5: pending.

Answers from the architect on 2026-10-28, for all points:
1. One food type per recipe. Other kinds of tags stay as they are, e.g. the time tag Rask and the meal type categories (Middag, Lunsj, Frokost ...).
2. Best effort on import (derived from the ingredients); the user can always change it.
3. Yes: the food type replaces the food tags Vegetar, Fisk, Kylling and Kjøtt (migrate them). Add filtering on food type to the recipe list.
4. "At least N per type per week" is enough for now.
5. Yes: hidden for kids; adults see them greyed out with the reason and can override.
6. Yes: kids pick dinners for the days of the week.
