# Q-009: Skip verifier and reviewer for the rest of L1
Raised by: orchestrator / L1 (T-003, T-019, T-004, T-018)
Status: answered

## Context
ADR 0009 and the L1 prompt gate every merge into `dev` on a green `./scripts/verify.sh` run by the verifier, plus verifier PASS and reviewer approval. T-014, T-002 and T-015 went through that gate. During T-003 the architect asked to speed up the first local version and not run verification.

## Options
1. Keep the full gate (verifier + reviewer) for every L1 task.
2. For the rest of L1 only: merge on the implementer's own evidence plus a green `./scripts/verify.sh` that the orchestrator runs on `dev` after the merge. No verifier or reviewer agent. Acceptance boxes stay unticked unless the implementer showed command output for them.
3. Skip all checks.

## Recommendation
Option 2. It keeps the cheap automated gate (build, tests, SQL password grep) and leaves a clear record of what was not independently checked.

## Answer (architect)
Option 2, decided by the architect on 2026-10-23 ("you do not need to verify for the initial first local version"). Applies to T-003 (its verifier was stopped mid-run), T-019, T-004 and T-018. Not a precedent for M0 and later: the full ADR 0009 gate applies again after L1.
