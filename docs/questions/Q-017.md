# Q-017: Recipe import parser strategy, and what happens to the original text
Raised by: orchestrator (from review of T-042) / task T-042, affects T-043
Status: answered

## Context
docs/backlog/T-042.md says the parser strategy (rule-based or LLM-assisted) is a product and cost decision to raise first. T-042 was implemented rule-based without raising it; the reviewer flagged the missing decision. The review also noted that a saved import keeps the original text / page JSON-LD indefinitely (only household deletion removes it).

## Options
Parser:
1. Rule-based only: deterministic, no per-import cost, nothing leaves the server; unclear lines flagged for manual fixing.
2. Rule-based with an optional AI fallback for lines the rules can't parse (per-import cost, sends text to an AI provider, needs a secret).
3. AI-first parsing of the whole recipe.

Original text after save:
1. Clear it on save; keep only the source URL as provenance.
2. Keep it indefinitely.
3. Keep it 30 days, then a cleanup job deletes it.

## Recommendation
Rule-based only; clear the original text on save.

## Answer (architect)
Decided by the architect on 2026-10-26: rule-based only (option 1); clear the original text and draft on save, keep only the source URL (option 1). Implemented in T-042.
