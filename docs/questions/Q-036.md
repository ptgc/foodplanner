# Q-036: How is the ingredient catalog given to Claude in a photo import?
Raised by: spec-writer, task T-118 (docs/specs/T-118-recipe-from-photo.md)
Status: open

## Context
Rule 5: ingredients are structured (catalog ingredient id + quantity + unit). The skill must make Claude turn "småpoteter" into the base ingredient "Potet" with a note, and keep "røde linser" and "grønne linser" apart. Q-034 does not say whether Claude sees the catalog. T-077 sends no catalog and no household data: Claude answers with names, and the server matches them (`IngredientMatcher`, threshold 0.8) against what the household can see. The privacy line promises "no names or account data".

## Options
1. **No catalog in the request. Claude returns a plain base-ingredient name in the page's language following the skill's rules; the server resolves it with `IngredientMatcher` (global + own, tenant filtered). A name that does not match stays "unmatched" with suggestions, and the review offers to create it as a new own ingredient (existing flow).** Smallest request, nothing about the household leaves the server, same trust model as T-077. Cost: the model cannot know which spelling the catalog prefers, so more lines may come back unmatched ("Potet" is fine, "Hermetiske tomater" vs the catalog's "Tomater på boks" is not).
2. **Send the names of the global catalog only** (about 300-500 names, about 3-5k tokens, identical for all households, so prompt caching makes it cheap), as a closed list the model prefers but may leave ("propose new" flag). Still no household data. Cost: more input tokens, a catalog that grows past the cache-friendly size needs care, the list must be versioned with the skill for the eval.
3. Send global plus the household's own ingredient names. Best matching for households with many own ingredients; but own names (free text typed by users) leave the server, which contradicts the current privacy text and needs T-113/T-117 wording and architect approval.

## Recommendation
Option 1 first, because it keeps the T-077 trust model and the eval will show the real match rate on the 17 recipes. If the unmatched share is above about 15 percent of lines, switch to option 2 (global names only, with prompt caching); option 3 only after an explicit privacy decision.
