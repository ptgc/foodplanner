# Q-022: May a kid remove any pick in an unlocked week, or only their own?
Raised by: spec writer / T-026
Status: open

## Context
Architect (Q-020 addendum, 2026-10-28): kids pick in the household's shared week plan "and can add and remove picks there". The T-030 rule and the T-026 spec say a Child changes or removes only entries they picked (in kid mode: entries picked by the active profile). "Remove" can be read as "my own picks" or as "any pick in an unlocked week". The spec keeps "own picks only" as the default until this is answered.

## Options
1. Own picks only (spec default). Siblings and parents' picks are safe from small hands; a kid cannot fix a parent's mistake.
2. Any pick in an unlocked week, but not change (date, servings). Easier to tidy the plan; a younger sibling can delete a brother's pick, and the "picked by" history is lost.
3. Any pick in an unlocked week, change and remove. Simplest to explain, weakest protection; the lock is then the only safeguard.

## Recommendation
Option 1. The week lock already gives adults a safeguard, and a deleted pick is annoying to a 4-year-old; option 2 can be added later by changing one policy.
