# ADR 0008: Oda integration

Status: proposed

## Context
No official public partner API found. Unauthenticated search endpoint exists; an authenticated API for cart operations exists but is undocumented. No EAN barcodes exposed.

## Decision
PENDING outcome of task T-001 spike. Use IShoppingListExporter adapter regardless; fall back to share/copy export if Oda is fragile.

## Consequences
Risk: undocumented endpoints, possible ToS conflict, credential storage. Contact Oda about partner access.
