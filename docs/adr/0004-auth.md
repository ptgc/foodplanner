# ADR 0004: ASP.NET Core Identity with external providers

Status: accepted

## Context
Want Google and usual providers; Entra judged overkill. Other families may join later.

## Decision
Identity with cookie auth; Google first, then Microsoft/Apple/Vipps via OIDC. Local email/passkey fallback. Link accounts only by verified email. Invite token survives the OAuth round trip. Hidden behind ICurrentUser.

## Consequences
We own security-sensitive code. Keycloak container is the upgrade path.
