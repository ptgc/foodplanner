# foodplanner

Family meal planning and shopping: pick the week's dinners, get a shopping list, cook from recipes.
Agent workflow and rules: `CLAUDE.md`. Plan, ADRs, specs and backlog: `docs/`.

> Status: iteration L1 (local only) is being built by the orchestrator. The sections after
> "Start the build" are filled in by task T-018 once the app runs.

## 1. Fresh machine setup (Windows)

Run in PowerShell. Package IDs other than Claude Code have not been verified on a real machine yet;
if one fails, run `winget search <name>` and tell the architect.

```powershell
winget install --id Git.Git -e
winget install --id Microsoft.DotNet.SDK.10 -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id jqlang.jq -e
winget install --id Microsoft.VisualStudioCode -e
winget install --id Anthropic.ClaudeCode -e
winget install --id SUSE.RancherDesktop -e
```

Why each one:
- **Git**: also provides Git Bash, which Claude Code uses to run the bash scripts and the safety hook.
- **.NET 10 SDK** and **Node LTS (22+)**: build the API and the web app.
- **jq**: used by the safety hook (`.claude/hooks/guard-bash.sh`) to read the commands Claude runs.
- **VS Code**: editor and debugger.
- **Claude Code**: the `claude` command-line tool that runs the orchestrator.
- **Rancher Desktop**: the container engine (SQL Server, API, web). Start it once, and in
  Preferences → Container Engine choose **dockerd (moby)**. Docker Desktop or Podman also work but
  are not what the scripts are tested with.

Close and reopen PowerShell after installing so the new commands are on PATH. Then:

```powershell
claude --version     # log in the first time you run `claude`
docker version
docker compose version
```

## 2. Clone

```powershell
mkdir C:\projects -Force
cd C:\projects
git clone https://github.com/ptgc/foodplanner
cd foodplanner
git switch dev
```

`dev` is the default branch. Never work on `test` or `prod`; they are promoted by PR.

## 3. Check the machine

```powershell
.\scripts\doctor.ps1
```

It checks Git, .NET, Node, jq, bash, the container engine, Claude Code and the branch, and prints
how to fix anything missing. If PowerShell blocks the script, run once:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

macOS/Linux: `./scripts/doctor.sh` (install commands are added by T-018).

## 4. Start the build

Open `claude` once in this folder and accept the trust prompt, then quit. Then:

```powershell
.\scripts\start-orchestrator.ps1
```

This runs `claude --agent orchestrator` with the prompt in `docs/prompts/local-iteration-1.md`.
The orchestrator builds one task at a time on `task/T-xxx-*` branches and merges them into `dev`
after the verifier and reviewer pass. It never touches `test` or `prod`.

## Secrets

No password is ever stored in the repo. The local SQL password is generated by
`scripts/local-secrets` into .NET user secrets on your machine (added by T-018).
